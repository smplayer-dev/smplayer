# SMPLAYER (fork)

SMPlayer is a free media player for Windows, Linux and Mac OS with YouTube support. This is a vibe-coded fork for Linux, that changes the "Open/Disc" menu to a more palatable form as per the description [here](https://github.com/smplayer-dev/smplayer/issues/1409) (see also photo below); this should be useful esp. for systems with multiple optical drives.
